Home

Melvbot is a single-user Telegram bot. It requests access to Google Calendar and Google Tasks so the owner can list, create, and update events and tasks from Telegram.

OAuth tokens are stored on the owner’s server. They are used only to call Google’s Calendar and Tasks APIs. Calendar and Tasks data is not sold, not used for advertising, and not shared with other companies except Google as needed to provide those APIs.

Contact: the Gmail address listed as the Google Cloud project’s user support email.
