# See doctor

Default GP: **FAITH Clinic (Bedok)**, Blk 746 Bedok Reservoir Rd, #01-3013, S470746. Tel **6702 0820**.

Hours (SGT), given as prose in Telegram: Mon–Fri 8:30–16:00 and 18:30–21:00 (closed 16:00–18:30); Sat–Sun 8:30–12:30; PH closed.

## Booking

- Existing patients: [appointment.jedatis.com](https://appointment.jedatis.com/) → FAITH Clinic (Bedok) → mobile + DOB on file. You cannot book on the user's behalf because it needs their credentials.
- New patients: no e-appointment; call or email the clinic.
- Walk-in: accepted; e-appointments usually get priority.

## When unwell

Mild: rest, fluids, paracetamol/ibuprofen if tolerated. Escalate to the GP on persistent fever, breathing difficulty, chest pain, dehydration, or worsening after 2–3 days.
